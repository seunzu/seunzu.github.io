# SeungJuSuh Personal Website

Next.js + TypeScript + Tailwind CSS portfolio site built from resume and portfolio PDFs.

## Structure

- `src/app/page.tsx` - main portfolio page
- `src/app/globals.css` - Tailwind import and shared primitives
- `public/documents/` - resume and portfolio PDFs
- `public/assets/` - rendered PDF previews used by the page

## Commands

```bash
pnpm install
pnpm dev
pnpm build
```
